# «Тюркский мост» (Turkic Bridge) — Оптовый B2B-маркетплейс

**«Тюркский мост»** — это B2B-платформа нового поколения, соединяющая турецких производителей текстиля (Денизли, Бурса, Стамбул) с розничными магазинами и сетями Казахстана (Алматы, Астана, Шымкент и др.).

---

## 🚀 Ключевые возможности

1. **Мультиязычный интерфейс (3 языка)**:
   - 🇷🇺 **Русский** (по умолчанию для Казахстана)
   - 🇹🇷 **Турецкий** (Türkçe для фабрик)
   - 🇰🇿 **Казахский** (Қазақ тілі)
   - Переключение на лету в шапке с авто-сохранением предпочтения.

2. **Двусторонний ИИ-перевод в реальном времени**:
   - Чат покупатель ⇄ фабрика: покупатель пишет на русском или казахском, поставщик получает автоперевод на турецкий (и наоборот).
   - В каждом сообщении отображается **оригинал** и **перевод ИИ**.
   - Серверный роут `/api/translate` адаптирован под специфику оптовой торговли текстилем (сохраняет плотность, граммаж, состав нити, размеры и цены).
   - Автоматический перевод карточки товара при добавлении турецким поставщиком.

3. **Безопасная сделка (Эскроу) и монетизация**:
   - Платформа взимает прозрачную комиссию **5%** с каждого заказа.
   - Оплата в тенге (KZT) с динамическим пересчетом по курсу USD.
   - Деньги покупателя замораживаются в Эскроу (`paid_in_escrow`). Фабрика начинает производство (`in_production`), отгружает товар (`shipped`). Выплата фабрике (`completed`) происходит только после прибытия и подтверждения в Казахстане.

4. **3 ключевые роли с моментальным переключателем в Header**:
   - 🛍️ **Покупатель (РК)**: Каталог с фильтрами по городам (Денизли, Бурса, Стамбул), MOQ, категориям; расчет партии; адрес доставки в РК; чат с фабрикой; отслеживание 7 статусов заказа.
   - 🏭 **Фабрика (Турция)**: Кабинет поставщика, управление каталогом (CRUD с ИИ-переводом), прием входящих заказов, обновление статусов производства и логистики.
   - 🛡️ **Администратор платформы**: Модерация и верификация турецких фабрик (бейдж «Проверенная фабрика»), мониторинг всех заказов, аналитика суммарной комиссии 5% и общего товарооборота.

## 🛠️ Стек технологий

- **Фреймворк**: Next.js 14 (App Router) + TypeScript
- **Стилизация**: Tailwind CSS (палитра Deep Navy `#0A2540` + Turkish Turquoise `#00D4B2`)
- **База данных**: PostgreSQL (Supabase) + Row Level Security (RLS)
- **Иконки**: Lucide React
- **Хранилище состояния**: Двойной режим — реактивный локальный `AppStore` (мгновенно работает из коробки) + клиент Supabase SSR для продакшена.

   **[http://localhost:3000](http://localhost:3000)**

## 🗄️ База данных (Supabase)

Скрипты создания таблиц и наполнения лежат в папке `supabase/`:
1. Откройте [Supabase Dashboard](https://supabase.com/dashboard) → **SQL Editor**.
2. Выполните скрипт `supabase/schema.sql` (создаст таблицы `profiles`, `suppliers`, `products`, `conversations`, `messages`, `orders`, `order_items`, `order_events` и RLS-политики).
3. Выполните скрипт `supabase/seed.sql` (наполнит базу 3 турецкими фабриками, 15 товарами и 2 покупателями).
4. Скопируйте `URL` и `anon key` проекта в файл `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
   OPENAI_API_KEY=your-api-key # Для LLM перевода
   ```

## 🧪 Сценарии для тестирования функционала

### Сценарий 1: Роль «Покупатель (РК)»
1. Откройте главную страницу, перейдите в **«Каталог»**.
2. Отфильтруйте товары по городу: выберите **Денизли** (столица домашнего текстиля).
3. Нажмите на товар (например, «Комплект постельного белья Ranforce 100% хлопок»).
4. Ознакомьтесь с MOQ, ценой в \$ и ₸, нажмите **«Оформить оптовый заказ»**.
5. Укажите адрес в Алматы/Астане, проверьте расчет комиссии 5% и нажмите **«Создать заказ»**.
6. В карточке заказа нажмите **«Оплатить в Эскроу»** — статус сменится на `paid_in_escrow`.
7. Нажмите кнопку **«Чат с фабрикой»** — напишите сообщение на русском или казахском языке, убедитесь, что ИИ подготовил турецкий перевод.

### Сценарий 2: Роль «Фабрика (Турция)»
1. В верхнем меню переключите роль на **«Фабрика: Denizli Pamuk»** (или переключите язык на **TR**).
2. Перейдите в **«Кабинет фабрики»** (`/dashboard/supplier`).
3. Во вкладке **«Входящие заказы»** примите заказ и переведите его на этап `in_production` (В производстве), затем `shipped` (Отгружен в Казахстан).
4. Во вкладке **«Добавить товар»** создайте новый товар на турецком языке — ИИ автоматически сформирует русское и казахское описания.

### Сценарий 3: Роль «Админ»
1. В шапке переключите роль на **«Администратор»**.
2. Перейдите в **«Админ-панель»** (`/dashboard/admin`).
3. Посмотрите статистику: общий оборот в USD/KZT и **суммарную комиссию платформы (5%)**.
4. В блоке «Заявки фабрик» верифицируйте новых поставщиков одним кликом.
